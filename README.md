## 👋 About My Journey

Welcome to my **90 Days of DevOps Journey!** 🚀

I'm starting this challenge to strengthen my technical fundamentals, gain practical experience, and build the skills required to begin my career in **Cloud Computing and DevOps**.

Instead of only learning theory, I want to apply every concept through hands-on practice, daily challenges, troubleshooting, documentation, and projects.

This repository will serve as my **public learning journal**, where I document what I learn, the tasks I complete, the problems I solve, and the progress I make throughout these 90 days.

My focus is simple: **learn consistently, practise practically, document honestly, and improve every day.**

## 🎯 My Goals

- 🐧 Build strong Linux and system administration fundamentals.
- 🌐 Understand networking, DNS, SSH, TCP/IP, and troubleshooting.
- 🔧 Learn Git and GitHub workflows, including branching and collaboration.
- ⚙️ Develop shell scripting and automation skills.
- 🐳 Understand Docker and containerization.
- ☁️ Gain hands-on experience with cloud platforms, especially AWS.
- 🔄 Learn CI/CD pipelines and deployment automation.
- ☸️ Understand Kubernetes and container orchestration.
- 🏗️ Practise Infrastructure as Code using Terraform and configuration management with Ansible.
- 📊 Explore monitoring, logging, and observability tools.
- 💻 Build practical projects and strengthen my GitHub portfolio.
- 💼 Prepare for entry-level Cloud Support, Cloud Operations, Linux Administration, and DevOps opportunities.
